# 燃知 App · 设计文档

> 一款读取 Apple 健康运动数据、结合个人身体数据进行统计分析并生成个性化建议的 iOS 应用。
> 版本：v1.0 设计稿　｜　平台：iOS 17+　｜　技术栈：SwiftUI + Swift Charts + HealthKit

---

## 1. 产品目标

把散落在「健康」App 里的运动与身体数据，聚合成**看得懂、能行动**的洞察：

- 一屏看清今日状态（活动评分 + 关键指标）
- 用图表呈现 7 天 / 30 天趋势，识别习惯变化
- 基于运动科学规则给出本地即时提示（离线可用）
- 结合大模型生成一份「像私教一样」的个性化周报建议

**隐私优先**：所有原始数据仅在本机处理；AI 建议只上传**聚合后的统计摘要**（不含姓名、精确位置等可识别信息），API Key 存于 Keychain。

---

## 2. 信息架构

```
燃知 App
├── 概览 (Dashboard)      —— 今日决策页：评分结论 + 主缺口 CTA + 提示 + 今日运动 + 睡眠影响 + 可展开趋势
├── 运动 (Workouts)       —— 训练汇总 + 类型统计/过滤 + 记录时间线 + 详情（轨迹/心率/分段配速）
├── 睡眠 (Sleep)          —— 昨夜评分与对比 + 分期时间轴 + 夜间生命体征 + 多指标趋势 + 作息规律 + 恢复关联
├── 身体 (Body)           —— 结论 + BMI/体重/体脂 + 趋势 + 恢复基线 + 代谢/TDEE + VO₂ Max（有则显示） + 精简档案
├── 建议 (AI Advice)      —— 上周 AI 周报（图文 + 历史）+ 即时建议 + 本地规则提示
└── 设置 (Settings)       —— 活动能量目标 + 大模型服务商/模型/Key + 授权状态
```

底部 **5 Tab**：概览 / 运动 / 睡眠 / 身体 / 建议。设置以模态弹层（Sheet）从概览页右上角进入。

## 3. 页面功能规格

### 3.1 概览 Dashboard（今日决策页）

> 产品原则：前 3 秒只回答「今天状态怎样？下一步做什么？」。从数据汇总页改为**今日决策页**。

| 模块 | 内容 | 交互 / 说明 |
|---|---|---|
| Hero 评分 | 活动评分环 + 短评 + 构成 chip（能量% · 锻炼是否达标） | 步数仅展示，不设目标；评分可解释 |
| 一句话结论 | 本地规则：缺口 + 睡眠恢复对今日强度的建议 | 如「还差 44 kcal…适合轻松有氧」 |
| 指标精简行 | 2×2：能量（带进度）/ 锻炼（带进度）/ 步数 / 距离 | 替代原大四宫格 + 独立周小结 |
| 主 CTA | 指向今日最大缺口的行动 | 未达标 →「建议」Tab 生成本日建议；已达标 →「今日目标已完成」或查看周报 |
| 今日提示 | Top 1–2，可点击跳转 | 优先「缺口行动」「睡眠影响」 |
| 今日运动 | 当日 Workout 列表 | **无则隐藏整卡** |
| 昨夜睡眠 | 时长 + 深睡 + 评分 + **对今日强度的一句话影响** | 点击进睡眠 Tab |
| 近 7 日洞察 | 默认一句话 + 关键数字；周环比 | **折叠**：点「查看趋势图表」才展开 |

**已确认**
1. CTA 未达标默认跳 **「建议」**
2. 今日无运动：**隐藏**「今日运动」卡（不显示空态）

### 3.2 运动 Workouts
- 时间范围：近7天 / 近1个月 / 近1年 / 自定义
- 顶部汇总 + 按类型统计（点选过滤列表）
- 记录时间线；游泳显示 /100m 配速
- 详情：指标网格、GPS 轨迹、心率曲线、分段配速（跑步 /km，游泳 /100m）、泳姿分布
  - **游泳详情（参考 Keep，HealthKit 可落地范围）**：
    - Hero：大字距离（m）+ 时段 + 池长/趟数 + 泳姿色点
    - 指标：总时长、均配速/100m、均/峰值心率、消耗、SWOLF（有划次时）、均划次/趟、最快配速
    - 分段趟表（泳姿着色）· 自动组合（按休息拆组）· 配速柱图
    - 泳姿分布 · 本场最佳分段（100/200/…）· 与历史均配速对比
    - 心率曲线 + 五区占比
    - 不做：水温/训练效果等非 HealthKit 标准字段；「本场最佳」≠ 历史个人纪录
- 分享：系统分享面板（图片+文案，支持存相册）
  - **海报化（已确认）**：像海报，不像仪表盘截图；分享前**不选手动模板**，按场景自动选：
    - 有 GPS 轨迹快照 → **轨迹海报**（全幅轨迹底 + 一个主指标 + 辅指标 + 短文案）
    - 无轨迹 → **极简大字**（配速或 kcal 主视觉）
    - 运动列表「区间汇总分享」→ **次数海报**：主指标为**次数**；下方按类型列出「次数 + 距离」（有距离）或「次数 + kcal」（无距离）；大数紧凑显示（如 `1,372 km`，游泳过大改 km）
  - 社交文案短；汇总与单次均优先 **AI 一句趣味文案**（无 Key/失败回退本地）；水印仅 `燃知`
  - 原型：`prototype/index.html#share`

### 3.3 睡眠 Sleep（本轮交互增强）

> 口径：只统计**过夜主睡眠**（排除午睡）；睡着时长用时间并集，避免多数据源重复累加。午睡单独以小卡露出。

| 模块 | 内容 | 交互 / 说明 |
|---|---|---|
| Hero 评分环 | 0–100 睡眠评分 + 昨夜时长 + 深睡/效率 + 入睡·起床 | 评分：时长50% + 深睡占比25% + 效率25% |
| 一句话结论 | 本地规则生成的昨夜解读 | 如「比平常早睡 18 分钟…今日宜轻松训练」 |
| vs 平常 | 三列：入睡 / 时长 / 深睡 相对近7晚均值 | 早/多 → 绿；晚/少 → 橙；持平中性 |
| 午睡小卡 | 有午睡时显示时长与时段 | 明确「不计入昨夜主睡眠」；无则隐藏 |
| 分期时间轴 | 简化 hypnogram（清醒/REM/核心/深睡 四行） | 横轴为昨夜入睡→起床；下方保留阶段占比条+图例 |
| 夜间生命体征 | 呼吸频率 / 血氧 / 腕温（三格） | 取主睡眠时段内均值（腕温为相对基线偏差）；缺数显示「暂无」；需 Watch + 授权 |
| 近7晚趋势 | 时长 / 深睡 / 效率 / 评分 四指标切换 | 分段控件切换同一柱状图；副标题显示对应日均 |
| 作息规律 | 每晚主睡眠时段横条 + 规律性评分 | 附说明文案；横轴约 21:00→次日 09:00 |
| 恢复关联 | 运动日深睡、静息心率、HRV、睡前运动提醒 | 本地规则；可随数据有无显隐 |

**生命体征数据口径**
| 指标 | HealthKit | 展示 | 缺失态 |
|---|---|---|---|
| 呼吸频率 | `respiratoryRate` | 主睡眠窗内平均值，单位「次/分」 | 格内「暂无」 |
| 血氧 | `oxygenSaturation` | 主睡眠窗内平均值，单位「%」 | 格内「暂无」 |
| 腕温 | `appleSleepingWristTemperature`（优先）或 `bodyTemperature` | 相对基线偏差 °C（如 +0.15）；无偏差数据则显示绝对值并标注 | 格内「暂无」 |

> 三者均为只读；页面脚注声明「不构成医疗诊断」。**任一指标有数据才显示整卡**；缺数的格显示「暂无」。腕温优先展示相对基线偏差。

**已确认（实现口径）**
1. 午睡小卡：**保留**
2. 趋势默认指标：**时长**
3. 「平常」对比窗口：**近 7 晚**（相对昨夜之外的均值；不足时用全部可用晚）
4. 生命体征全无：**隐藏整卡**；部分有数则缺格「暂无」
5. 腕温：**相对基线偏差**（无偏差数据时降级绝对值并标注）

### 3.4 身体 Body（趋势 + 恢复基线）

> 产品原则：从「静态档案」改为「我变得怎样」——看趋势、看恢复基线、连代谢与训练目标。与睡眠页区分：睡眠讲**昨夜**，身体讲**近周/近月体质基线**。

| 模块 | 内容 | 交互 / 说明 |
|---|---|---|
| Hero 结论 | 一句话身体状态 + 对训练强度建议 | 本地规则（BMI/体脂/静息心率） |
| 三指标 | BMI（中国标准）/ 体重 / 体脂 | 保留；有变化时结论优先 |
| 体重·体脂趋势 | 折线 + 较周期初差值 | 近30天 / 近90天切换；无历史则隐藏图表留最新值 |
| 恢复基线 | 静息心率、HRV、7日均心率 + 一句解读 | 近7日体质，非昨夜；与睡眠页文案区分 |
| 代谢估算 | BMR（Mifflin-St Jeor）+ 估算 TDEE | TDEE = BMR × 活动系数（按近7日活动水平映射）；关联能量目标说明 |
| 心肺适应 | VO₂ Max | **有数据才显示整卡**；无则隐藏 |
| 个人档案 | 年龄 / 性别 / 身高 | 去掉与 Hero 重复的体重、BMI |
| 身体提示 | Top 1–2 本地规则 | 体成分区间、体重变化节奏等 |

**已确认（实现口径）**
1. TDEE：按近7日锻炼分钟分档（久坐 1.2 / 轻度 1.375 / 中度 1.55 / 较高 1.725）
2. VO₂ Max：无数据 **隐藏整卡**
3. 体重趋势默认：**近30天**（可切近90天）

### 3.5 建议 AI Advice

| 模块 | 内容 | 交互 / 说明 |
|---|---|---|
| **上周周报（唯一主卡）** | 紧凑摘要：日期 · 状态标签 · 一句话 · 大评分 | 点进详情看指标/亮点/行动；周一自动生成 |
| 图文周报详情 | JSON：headline / vibe / highlights / metricNotes / actions | 右上角分享海报 |
| 今日提示 | 规则引擎 tips（最多 3 条） | 无 Key 也可看 |
| 近况建议 | 近 7 / 30 天滚动建议（普通白卡，可折叠） | 「生成近况建议」；不与周报抢 Hero |
| 历史周报 | 按周列表 | 主卡右上角「历史」入口 |

- 上传内容仅为聚合统计摘要，不含隐私；明确「不构成医疗诊断」

## 4. 数据字段清单（HealthKit 只读）

| 分类 | HealthKit 标识 | 用途 |
|---|---|---|
| 日常活动 | stepCount, distanceWalkingRunning, activeEnergyBurned, appleExerciseTime, appleStandTime, flightsClimbed | 每日趋势与评分 |
| 运动训练 | HKWorkout（时长/消耗/距离） | 运动记录页 |
| 心率 | heartRate, restingHeartRate, heartRateVariabilitySDNN | 心率指标与区间；身体页恢复基线 |
| 身体数据 | bodyMass, height, bodyFatPercentage, bodyMassIndex | BMI/体脂/代谢；体重历史趋势 |
| 心肺适能 | vo2Max | 身体页 VO₂ Max（有则显示） |
| 个人特征 | dateOfBirth, biologicalSex | 年龄/性别（用于代谢公式） |
| 睡眠 | sleepAnalysis（深睡/核心/REM/清醒） | 睡眠页主睡眠与午睡拆分、分期时间轴 |
| 夜间生命体征 | respiratoryRate, oxygenSaturation, appleSleepingWristTemperature（/bodyTemperature） | 睡眠页三格；主睡眠窗内均值 |

> 均为**读取**权限，App 不写入任何健康数据。

## 5. 分析逻辑

- **活动评分**：`min(步数/目标,1)×40 + min(能量/400,1)×30 + min(锻炼/30,1)×30`
- **周期汇总**：总量、日均、达标天数、最活跃日、周环比趋势
- **BMI 分级**：中国成人标准（<18.5 偏瘦 / 18.5–23.9 正常 / 24–27.9 超重 / ≥28 肥胖）
- **基础代谢**：Mifflin-St Jeor 公式
- **本地规则提示**：步数达标、WHO 每周 150 分钟运动量、趋势预警、静息心率评估、BMI 提醒等

## 6. 大模型集成

- OpenAI 兼容协议（可换 Base URL 接国内模型如 DeepSeek/通义/Kimi 等）
- 两类生成：
  1. **上周周报** `generateWeeklyReview`：日历周切片摘要 → 结构化 Markdown 周报
  2. **即时建议** `generateAdvice`：近 7 / 30 天滚动摘要 → 短建议
- **上传内容仅为统计摘要**：年龄段、身高体重、BMI、心率、睡眠汇总、活动/锻炼、该周运动列表；不含姓名、GPS、原始逐条记录
- 周报历史：`AdviceHistoryStore` JSON 落盘 Application Support
- API Key 存 Keychain，不落 UserDefaults、不进日志

## 7. 技术架构

```
SportHealthApp（入口，展示名：燃知）
 └── HealthViewModel (@Observable 数据中枢)
      ├── HealthKitManager   读取健康数据（async/await）
      ├── AnalysisEngine     本地统计/评分/规则/摘要/自然周 payload
      ├── AIService          大模型调用（即时建议 + 上周周报）
      └── AdviceHistoryStore 上周周报历史持久化
 Views: RootTabView / Dashboard / Workouts / Sleep / Body / AIAdvice / Settings
 Utils: KeychainHelper / Extensions / Brand
```

- 单向数据流：View 观察 ViewModel，ViewModel 调用 Service
- 数据读取并发（async let）提升首屏速度
- 目标/接口配置持久化到 UserDefaults，密钥到 Keychain

## 8. 隐私与合规

- Info.plist 声明 `NSHealthShareUsageDescription`（读取用途）
- 首次进入显式授权引导；系统不告知具体授权项，代码对缺失数据做判空降级
- AI 功能需用户主动配置并触发，默认关闭
- 明确免责声明：分析建议基于运动科学一般规律，非医疗诊断
