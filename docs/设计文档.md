# 燃知 App · 设计文档

> 一款读取 Apple 健康数据、在本地完成统计分析，并可选接入大模型生成个性化建议的 iOS 应用。  
> **展示名**：燃知　｜　Slogan：读懂健康，燃得明白　｜　Bundle ID：`com.workbuddy.SportHealth`  
> **版本**：v1.0（核心功能已落地）　｜　平台：iOS 17+　｜　技术栈：SwiftUI + Swift Charts + HealthKit + MapKit  
> **仓库**：https://github.com/stoneslshi/Sport　｜　交互原型：`prototype/index.html`

---

## 1. 产品目标

把散落在「健康」App 里的运动与身体数据，聚合成**看得懂、能行动**的洞察：

- 一屏看清今日状态（活动评分 + 关键指标）
- 用图表呈现 7 天 / 30 天趋势，识别习惯变化
- 基于运动科学规则给出本地即时提示（离线可用）
- 结合大模型生成「像私教一样」的**上周图文周报**与**近况建议**

**隐私优先**：所有原始数据仅在本机处理；AI 只上传**聚合后的统计摘要**（不含姓名、精确位置等可识别信息），API Key 存于 Keychain。分享水印与话题为 `燃知` / `#燃知`。

---

## 2. 信息架构

```
燃知 App
├── 概览 (Dashboard)   —— 今日决策页：评分 + 结论 + CTA + 提示 + 今日运动 + 昨夜睡眠 + 可展开趋势
├── 运动 (Workouts)    —— 区间汇总 + 类型过滤 + 时间线 + 详情（轨迹回放 / 心率五区 / 爬升 / 游泳明细）
├── 睡眠 (Sleep)       —— 昨夜评分与对比 + 分期 + 生命体征 + 趋势 + 作息 + 恢复关联
├── 身体 (Body)        —— 结论 + BMI/体重/体脂趋势 + 恢复基线 + 代谢/TDEE + VO₂ Max + 档案
├── 建议 (Advice)      —— 上周周报（主卡）+ 今日提示 + 近况建议；设置从右上角进入
└── 设置 (Settings)    —— Sheet：活动能量目标 + Garmin FIT 导入 + 大模型服务商/模型/Key + 隐私说明
```

底部 **5 Tab**：概览 / 运动 / 睡眠 / 身体 / 建议。设置以模态 Sheet 从**概览**或**建议**右上角进入（非独立 Tab）。

## 3. 页面功能规格

### 3.1 概览 Dashboard（今日决策页）

> 产品原则：前 3 秒只回答「今天状态怎样？下一步做什么？」。

| 模块 | 内容 | 交互 / 说明 |
|---|---|---|
| Hero 评分 | 活动评分环 + 短评 + 构成 chip（能量% · 锻炼是否达标） | 步数仅展示，不设目标；评分可解释 |
| 一句话结论 | 本地规则：缺口 + 睡眠恢复对今日强度的建议 | — |
| 指标精简行 | 2×2：能量（进度）/ 锻炼（进度）/ 步数 / 距离 | — |
| 主 CTA | 指向今日最大缺口的行动 | 未达标 →「建议」Tab；已达标 → 完成态 |
| 今日提示 | Top 1–2，可点击跳转 | 优先缺口行动、睡眠影响 |
| 今日运动 | 当日 Workout 列表 | **无则隐藏整卡** |
| 昨夜睡眠 | 时长 + 深睡 + 评分 + 对今日强度影响 | 点击进睡眠 Tab |
| 近 7 日洞察 | 一句话 + 关键数字；周环比 | **折叠**：点「查看趋势图表」展开 |
| 未授权 | 授权引导 | 首次进入请求 HealthKit |

**已确认**
1. CTA 未达标默认跳 **「建议」**
2. 今日无运动：**隐藏**「今日运动」卡

### 3.2 运动 Workouts

- 时间范围：近7天 / 近1个月 / 近1年 / 自定义
- 顶部汇总 + 按类型统计（点选过滤列表）
- 记录时间线；游泳显示 /100m 配速
- 区间汇总分享（次数海报）

#### 运动详情（通用）

| 能力 | 说明 |
|---|---|
| 指标网格 | 消耗、时长、距离、配速、心率、累计爬升等 |
| GPS 轨迹 | 缩略图 → 独立页「动态回放」：从起点描线、分段标注、播放/暂停/跟随 |
| 爬升曲线 | 有有效 GPS 海拔起伏时展示（最低/最高/累计爬升） |
| 心率曲线 | 有采样时展示 |
| 心率区间 | **五段式**（热身 / 燃脂 / 有氧耐力 / 无氧耐力 / 极限）；阈值约 60/70/80/90% 最大心率（优先年龄 `220−年龄`） |
| 分段配速 | 跑步等按 km；游泳按 100m |
| 分享 | 右上角；有轨迹 → 轨迹海报，否则 → 极简大字；文案优先 AI 一句 |

#### 游泳详情（参考 Keep，HealthKit 可落地范围）

- Hero：大字距离（m）+ 时段 + 池长/趟数 + 泳姿色点
- 指标：总时长、均配速/100m、均/峰值心率、消耗、SWOLF、均划次/趟、最快配速
- 分段趟表 · 自动组合（按休息拆组）· 配速柱图
- 泳姿分布 · 本场最佳分段（100/200/…，本场连续趟，非历史 PB）· 与历史均配速对比
- 心率曲线 + 五区占比
- **不做**：水温、训练效果等非 HealthKit 标准字段
- **说明**：泳池游泳通常无 GPS，故轨迹/爬升卡主要出现在跑步/骑行等户外运动

#### 分享海报（自动选模，无手动切换）

| 场景 | 模板 |
|---|---|
| 单次有 GPS 快照 | **轨迹海报** |
| 单次无轨迹 | **极简大字**（配速或 kcal） |
| 运动列表区间汇总 | **次数海报**（主指标次数 + 分类型次数/距离或 kcal） |
| 上周周报详情 | **周报海报**（评分 + 关键指标 + 行动） |

社交文案短；优先 AI 趣味句（无 Key/失败回退本地）；水印仅「燃知」。原型对比页：`prototype/index.html#share`（原型可手动切模板，App 正式自动选模）。

### 3.3 睡眠 Sleep

> 口径：只统计**过夜主睡眠**（排除午睡）；睡着时长用时间并集。午睡单独小卡露出。

| 模块 | 内容 | 交互 / 说明 |
|---|---|---|
| Hero 评分环 | 0–100 + 昨夜时长 + 深睡/效率 + 入睡·起床 | 评分：时长50% + 深睡占比25% + 效率25% |
| 一句话结论 | 昨夜解读 | 本地规则 |
| vs 平常 | 入睡 / 时长 / 深睡 相对近7晚 | 早/多→绿；晚/少→橙 |
| 午睡小卡 | 时长与时段 | 不计入主睡眠；无则隐藏 |
| 分期时间轴 | hypnogram（清醒/REM/核心/深睡） | + 阶段占比条 |
| 夜间生命体征 | 呼吸 / 血氧 / 腕温 | 全无则隐藏整卡；缺格「暂无」 |
| 近7晚趋势 | 时长 / 深睡 / 效率 / 评分 | 分段切换；默认时长 |
| 作息规律 | 横条 + 规律性评分 | — |
| 恢复关联 | 运动日深睡、静息心率、HRV、睡前运动提醒 | 随数据显隐 |

**生命体征口径**：主睡眠窗内均值；腕温优先相对基线偏差，否则绝对值并标注。脚注声明不构成医疗诊断。

### 3.4 身体 Body

> 睡眠讲**昨夜**，身体讲**近周/近月体质基线**。

| 模块 | 内容 | 交互 / 说明 |
|---|---|---|
| Hero 结论 | 身体状态 + 对训练强度建议 | BMI/体脂/静息等规则 |
| 三指标 | BMI（中国标准）/ 体重 / 体脂 | — |
| 体重·体脂趋势 | 折线 + 周期差值 | 近30 / 近90天；AreaMark 已裁剪防越界 |
| 恢复基线 | 静息心率、HRV、7日均心率 | 近7日体质 |
| 代谢估算 | BMR（Mifflin-St Jeor）+ TDEE | TDEE 按近7日锻炼分钟分档 |
| 心肺适应 | VO₂ Max | **有数据才显示** |
| 个人档案 | 年龄 / 性别 / 身高 | — |
| 身体提示 | Top 本地规则 | 与其它卡同宽 |

**TDEE 分档**：久坐 1.2 / 轻度 1.375 / 中度 1.55 / 较高 1.725（按近7日锻炼分钟）。

### 3.5 建议 Advice

> 一屏一条主线：周报为主，提示与近况为辅，避免双 Hero。

| 模块 | 内容 | 交互 / 说明 |
|---|---|---|
| **上周周报（唯一主卡）** | 日期 · vibe 标签 · 一句话 · 大评分 · 训练摘要 | 点进详情；周一首次打开且有 Key 时自动生成 |
| 图文周报详情 | 指标宫格（可附短注）· 亮点图标行 · 本周行动 · 分享 | 右上角分享海报 |
| 今日提示 | 规则引擎 tips（最多 3 条） | 无 Key 也可看 |
| 近况建议 | 近 7 / 30 天滚动 Markdown | 普通白卡，可展开/收起；「生成近况建议」 |
| 历史周报 | 按周列表（最多约 52 周） | 主卡「历史」入口 |

**周报 AI 结构（`WeeklyAdviceBrief` JSON，非长文 Markdown）**

```json
{
  "headline": "≤20字点评",
  "vibe": "2–4字标签",
  "highlights": [{"symbol":"run|sleep|…","title":"…","detail":"…"}],
  "metricNotes": [{"key":"score|workouts|…","note":"≤14字"}],
  "actions": ["行动1","行动2","行动3"]
}
```

旧版 Markdown 记录可降级为短结构展示。持久化：`AdviceHistoryStore` → Application Support `weekly_advice_history.json`。

## 4. 数据字段清单（HealthKit 只读）

| 分类 | HealthKit 标识 | 用途 |
|---|---|---|
| 日常活动 | stepCount, distanceWalkingRunning, distanceCycling, activeEnergyBurned, appleExerciseTime, appleStandTime, flightsClimbed | 每日趋势与评分 |
| 游泳 | distanceSwimming, swimmingStrokeCount | 距离、划次、SWOLF、均划次 |
| 运动训练 | HKWorkout, workoutRoute | 记录列表、详情、轨迹与海拔 |
| 心率 | heartRate, restingHeartRate, heartRateVariabilitySDNN | 曲线、五区、恢复基线 |
| 身体 | bodyMass, height, bodyFatPercentage, bodyMassIndex, vo2Max | BMI/体脂/代谢/心肺（BMI 以身高体重本地计算为主） |
| 个人特征 | dateOfBirth, biologicalSex | 年龄/性别、代谢与心率区间 |
| 睡眠 | sleepAnalysis | 主睡眠/午睡/分期 |
| 夜间生命体征 | respiratoryRate, oxygenSaturation, appleSleepingWristTemperature, bodyTemperature | 睡眠页三格 |

> 均为**读取**权限（`toShare: []`），App 不写入任何健康数据。

## 5. 分析逻辑

- **活动评分**（与代码一致）：活动能量占 **60%** + 锻炼时长占 **40%**（对标每日锻炼目标分钟）；**步数不计入评分**、不设步数目标
- **周期汇总**：总量、日均、能量达标天数、最活跃日、周环比
- **BMI 分级**：中国成人标准（&lt;18.5 偏瘦 / 18.5–23.9 正常 / 24–27.9 超重 / ≥28 肥胖）
- **基础代谢**：Mifflin-St Jeor
- **本地规则提示**：能量达标、WHO 每周 150 分钟、趋势、静息心率、BMI、睡眠与恢复关联等
- **自然周切片**：周一开周；上周周报用「上一自然周」活动 / 运动 / 睡眠 + 身体快照

## 6. 大模型集成

- OpenAI 兼容 Chat Completions（可换 Base URL）
- 三类生成：
  1. **上周周报** `generateWeeklyReview` → 结构化 JSON（`WeeklyAdviceBrief`）
  2. **近况建议** `generateAdvice` → 短 Markdown
  3. **分享文案** `generateShareCaption` → 一句趣味短文（失败回退本地）
- 上传内容仅为聚合统计摘要；不含姓名、GPS 点列、原始逐条采样
- 周报历史本地 JSON 落盘；API Key 仅 Keychain

## 7. 技术架构

```
SportHealthApp（入口，展示名：燃知；启动仅用 LaunchScreen，无二次 Splash）
 └── HealthViewModel (@Observable 数据中枢)
      ├── HealthKitManager      读取 Apple 健康（async/await）
      ├── GarminFitImporter     解析 Garmin 数据管理导出的 FIT / 嵌套 ZIP
      ├── ImportedWorkoutStore  导入活动本地缓存
      ├── HealthDataMerger      HealthKit / FIT 去重合并
      ├── AnalysisEngine        统计 / 评分 / 规则 / 自然周 payload
      ├── AIService             近况建议 + 上周周报 + 分享文案
      └── AdviceHistoryStore    周报历史持久化
 Views: RootTabView / Dashboard / Workouts / WorkoutDetail / WorkoutRouteMap
        Sleep / Body / AIAdvice / Settings / ShareComponents / MarkdownText
 Utils: KeychainHelper / Extensions / Brand
 Models: Health / Sleep / Insight / WeeklyAdvice / LLMProvider / HealthDataSource
```

- 单向数据流：View 观察 ViewModel，ViewModel 调用 Service
- 详情页并发加载心率 / 轨迹 / 游泳明细 / 分段
- 目标与 LLM 选项 → UserDefaults；密钥 → Keychain
- Garmin：本机选择 `.fit` 或数据导出 ZIP（含 `UploadedFiles_*.zip`），解析后与 HealthKit 按开赛时间重叠去重

## 8. 隐私与合规

- Info.plist 声明 HealthKit 读取用途说明
- 首次进入显式授权；缺失数据判空降级
- AI 需用户配置 Key 并主动/自动触发；默认无 Key 时本地提示仍可用
- 各页脚注：分析建议基于运动科学一般规律，**不构成医疗诊断**
